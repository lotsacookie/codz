# World at War stand-in textures

Generic fallbacks for Black Ops 3 Radiant maps (see `../iwmap-material.js`), used only when the map's zip has no image
for a material. Downscaled to 256x256 from `arrowsv/T5-WaW-Textures` (Treyarch / Activision assets, same notice as
`ASSET_NOTICE.md`).

| file | source | used for |
| --- | --- | --- |
| `tile.webp` | `berlin_floors_concrete_tile6_c` | tile materials, `dark_grey_floortile_c_new` (`zm_alien_isolation`) |
| `metal.webp` | `berlin_floors_metal_rivets3_c` | metal materials with a real colour map |
